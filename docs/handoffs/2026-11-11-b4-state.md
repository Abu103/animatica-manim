## The bug that was hiding behind the "fast" work

The suite could not simply be parallelised: the timeline geometry tests failed
at random under `-n 4`. Manim caches every rendered text as an SVG under
`<media_dir>/texts`, keyed by the text and the style -- **but not by the
process**. Two workers that render the same string write the same file and one
reads it half written. Proof: eight processes rendering one string into one
media directory -> `xml.etree.ElementTree.ParseError: no element found`. Every
process now gets its own `media_dir` (`tests/conftest.py`).

## The LaTeX packages were incomplete (fixed in PR #22, #23, #24)

Neither TinyTeX bundle carried `varwidth.sty`, and `standalone.cls` loads it for
its border box: **every formula failed to compile and the equations degraded to
plain text**, while `animatica doctor` reported LaTeX as fine (the package check
only compiles a formula with `--deep`).

- `varwidth` is in `TEX_PACKAGES` and `NEEDED_TEX_FILES` -> `doctor --fix` installs it.
- On Linux the doctor leaves the packages to apt, except when the TeX is a
  TinyTeX bundle (what the one-line installer unpacks) -- only tlmgr can complete
  that tree. `_tex_is_bundle()` recognises it; the system TeX Live is still apt's.
- `scripts/bootstrap.sh` completes the bundle after unpacking it, with the
  doctor's own package list.
- The bundles were rebuilt and republished:
  - **Linux** `animatica-tex.tar.xz` on the `native-deps-v1` release (clobbered
    by `tex-deps.yml`) and on the `artifacts` branch. Verified: it carries
    `texmf-dist/tex/latex/varwidth/varwidth.sty`.
  - **Windows** a new release `tex-deps-v2-windows` carries `tinytex-manim-win.zip`
    (and `tinytex-manim.zip`, the Linux fallback) with varwidth. The bundle is
    **not reproducible** -- it is built from whatever TinyTeX the upstream
    installer fetches that day -- so a rebuilt bundle gets a **new tag and a new
    hash**, and `src/animatica/tex_bundle.py` is pinned to the pair.

## How to work here

- The fast lane: `pytest tests/test_<component>.py -q` while you work,
  `python scripts/ci_tests.py` once before the PR, `python scripts/ci_render_gate.py`
  for the corpus (2 s when nothing changed).
- `ANIMATICA_TEST_JOBS=N` sets the suite's workers, `ANIMATICA_RENDER_JOBS=N` the
  gate's, `ANIMATICA_NO_RENDER_CACHE=1` forces a real render.
- The gate's render cache is keyed by the storyboard *and* a fingerprint of every
  source file, so a changed component is never served from it.
- `main` is protected: every change goes through a PR (squash), and
  `required_linear_history` means no merge commits on `main`.
